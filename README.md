# 区域课程本地化发布平台

面向东盟多国国际中文课程的本地化发布领域层。以一个经过批准的**基础课程版本**为唯一源头，
各地区在其之上提交本地化变更；平台自动计算上游修订对地区分支的影响，按变更类型执行
角色组合审批，并驱动可恢复、可隔离重试、可紧急撤回的发布批次。

## 领域模型（src/locale_release/）

| 模块 | 职责 |
| --- | --- |
| `contracts.py` | 基础契约：版本化实体、变更类型（术语覆盖/案例替换/课时调整/合规说明）、审批角色 |
| `content.py` | 内容单元、不可变基础课程快照（SHA-256 摘要）、依赖版本 |
| `localization.py` | 地区分支与本地化变更；上游影响计算（过期 / 未解决差异）、显式继承新修订 |
| `approval.py` | 按变更类型的角色组合审批台账；合作院校发布确认（绑定内容摘要与有效期） |
| `release.py` | 发布批次：阻断检查 → 锁定摘要与依赖 → 提交；隔离重试；紧急撤回阶段流水线 |
| `status.py` | 状态查询：两地继承差异对比、阻断原因、重启接续位置 |
| `platform.py` | 门面：聚合全部对象，JSON 检查点持久化（原子写入），重启后从断点接续 |

## 关键规则

- **单一事实来源**：以批准的基础课程快照为源；批次锁定快照摘要、分支内容摘要与依赖版本，
  发布过程中内容再变动也不影响本批次。
- **上游影响自动计算**：总部发布新修订时，命中被修改单元的变更转为“过期待确认”，
  目标单元被删除的转为“存在未解决差异”，既有审批全部作废；地区重新确认、重走审批后
  显式继承新修订。
- **组合审批**：术语覆盖＝语言专家＋合作院校；案例替换＝学科负责人＋语言专家；
  课时调整＝学科负责人＋合作院校；合规说明＝三方齐备。
- **发布阻断**：存在过期确认、未解决差异、驳回、审批未完成、院校确认缺失/过期/不匹配，
  或分支修订与批准基础版本不一致时，该地区不能发布。
- **隔离重试**：批次按地区独立推进；个别地区失败可隔离，其他地区照常完成，失败地区随后
  从失败的阶段单独重试。
- **紧急撤回**：已发布地区回到依赖主版本兼容的最近历史版本，并强制等待合作院校重新确认；
  无兼容版本时报告阻断原因。
- **可恢复**：每个阶段完成即写检查点；重新实例化平台并再次 `run_batch` 即从原执行
  （或回滚）位置接续。

## 运行

    python3 -m unittest discover -s tests -v      # 15 个端到端测试
    python3 -m compileall -q src tests run_cli.py # 编译检查
    python3 run_cli.py                            # 发布流程冒烟演示
